# Rapsometeddy Sports Predictor

Mobile-first football outcome predictor.

## V1
- Home/draw/away probability estimates
- Predicted score
- Recent-form, scoring and home-advantage factors
- Responsive dashboard

## Roadmap
1. Connect live football fixtures/results API
2. Store matches and predictions in Supabase
3. Add historical backtesting
4. Upgrade to Elo + Poisson model
5. Telegram bot integration

Predictions are estimates, not guarantees.
